# OTORONCARS LTD Website

Static website for GitHub Pages or Cloudflare Pages.

Includes 120 demo inventory records, 120 separate crawlable vehicle pages, filters, unique metadata, vehicle structured data, sitemap.xml and robots.txt.

Before publishing: replace demo cars in `cars.json`, replace `0000000000` with the real WhatsApp number, add real images to `images/`, then publish and connect `www.otoroncarsltd.com`.

Google controls crawling/indexing; a sitemap helps discovery but does not guarantee immediate indexing or rankings.


### Branding
The supplied OTORONCARS logo is included as `images/otoroncars-logo.png` and is used in the site header and favicon.
